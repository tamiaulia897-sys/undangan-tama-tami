# Website Undangan Tama & Tami

## Cara menerbitkan dengan GitHub Pages
1. Buat repository baru di GitHub, misalnya `undangan-tama-tami`.
2. Unggah `index.html` dan folder `assets` (isi seluruh file di dalamnya) ke root repository.
3. Buka Settings > Pages.
4. Pada Build and deployment, pilih Deploy from a branch.
5. Pilih branch `main` dan folder `/ (root)`, lalu Save.
6. Tunggu hingga GitHub Pages menampilkan alamat website.

Tombol Copy menggunakan Clipboard API (HTTPS GitHub Pages) dan menyalin nomor rekening BTN/BCA sesuai tombol yang ditekan.
